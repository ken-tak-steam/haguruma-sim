# 歯車シミュレータ君

技術の授業で、歯数と回転速度・回転方向の関係を確かめるブラウザアプリです。

## 使い方

1. `index.html` をブラウザで開きます。
2. パレットの20・40・60枚の歯車を、第1軸の上段にドラッグします。
3. 「+ 新しい軸」へ歯車をドラッグして次の軸を追加します。
4. 前の軸の上段と次の軸の下段を組み合わせ、「スタート」を押します。
5. モーター速度、回転数表示、計算式の表示を切り替えて観察します。

歯車はクリックすると取り外せます。「位置リセット」は回転角と回転数を戻し、「リセット」は配置を初期状態に戻します。計算式の伝達比は、出力回転速度÷入力回転速度を表します。

## 通信とプライバシー

画面表示用の Tailwind CSS を `https://cdn.tailwindcss.com` から読み込むため、インターネット接続が必要です。完全オフライン対応ではありません。通常のWebアクセスと同様に、IPアドレス等の通信情報が配信事業者へ伝わる場合があります。シミュレーション設定や結果を外部へアップロードする処理、解析・広告機能は設けていません。
